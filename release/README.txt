STARFIELD CREATIONS - PS5 GLYPH FIX
==================================
Author: VexenDeimos
Standalone optional Starfield interface fix for PC players using a DualSense.
Does NOT require Starfield Advanced DualSense (SAD), DSX, or an SFSE plugin.

WHAT IT CORRECTS
Category List - L2
Search - L1
Load Order - Triangle
Options - PlayStation Menu/Options
Purchase Credits - Square
Select - Cross
Back - Circle

TESTED
Directly connected DualSense with DSX disabled: Creations, Data menu, and
normal gameplay menus appeared correct in the author's tests.
Xbox controllers / Xbox-emulation modes have not been comprehensively tested.

IMPORTANT
This fix changes shared controller font entries used outside Creations.
Xbox controller users may see PS5 symbols in normal game menus.
Other mods providing fonts_en.gfx and/or fonts_en.swf will conflict.
After game updates, check compatibility before reusing these files.

INSTALLATION
Vortex / Mod Organizer 2: Install this ZIP and give it priority over other
mods replacing the same font files if you want these PlayStation glyphs.

Manual: Quit Starfield, back up any existing loose font files, then extract
both files from Interface/ into <Starfield install>/Data/Interface/.
Do NOT edit or overwrite the game's BA2 archives.

UNINSTALLATION
In Vortex/MO2, disable or remove the optional mod. For manual installs,
remove only the two loose files installed by this fix and restore backups.

SOURCE
Built reproducibly using original, legitimately obtained Bethesda font files.
Starfield game assets belong to Bethesda. This is an unofficial fan-made mod.
